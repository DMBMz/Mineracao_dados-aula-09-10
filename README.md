# Mineração de Dados - Web Scraping (Aula 09/10)

Repositório dedicado aos exercícios práticos de Web Scraping utilizando Python, `requests` e `BeautifulSoup`.

---

## 📚 Conteúdo

- [**Exercício 1 — Catálogo de cursos**](./exercicio_1/)
  - `index.html`: Página local da escola fictícia TechNova Academy.
  - `scraper.py`: Script de raspagem do catálogo com extração de cursos, carga horária, área e assuntos.
  - `README.md`: Documentação específica do exercício 1.
- `Exercicios_Webscraping.pdf`: Enunciados dos exercícios.
- `comandos.txt`: Comandos de apoio para ambiente e servidor local.

---

## 🛠️ Tecnologias e Bibliotecas

- **Python 3**
- **BeautifulSoup4 (`bs4`)**
- **Requests**
- **Servidor HTTP Local (`python -m http.server`)**
